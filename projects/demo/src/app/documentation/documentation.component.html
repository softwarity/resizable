Documentation

Installation

npm install @softwarity/resizable

Basic Usage

The library provides native Web Components that work with any framework or vanilla JavaScript.

<!-- Simple horizontal split -->
<resizable-split direction="horizontal">
  <resizable-panel flex="1">Left Panel</resizable-panel>
  <resizable-panel flex="2">Right Panel</resizable-panel>
</resizable-split>

Nested Layouts

Create complex layouts by nesting splits:

<resizable-split direction="vertical">
  <resizable-panel flex="1">
    <resizable-split direction="horizontal">
      <resizable-panel flex="1">Panel A</resizable-panel>
      <resizable-panel flex="1">Panel B</resizable-panel>
    </resizable-split>
  </resizable-panel>
  <resizable-panel flex="1">Bottom Panel</resizable-panel>
</resizable-split>

Angular Integration

For Angular projects, add CUSTOM_ELEMENTS_SCHEMA to your component:

import { Component, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';
import '@softwarity/resizable';

@Component({
  selector: 'my-component',
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
  template: `
    <resizable-split direction="horizontal">
      ...
    </resizable-split>
  `
})
export class MyComponent {}

API Reference

<resizable-split>

Attribute Type Default Description
direction 'horizontal' | 'vertical' 'horizontal' Direction of the split layout
min-panel-size number 50 Minimum panel size in pixels

<resizable-panel>

Attribute Type Default Description
flex number 1 Initial flex ratio for the panel
min string null Minimum size (e.g., "100px", "20%")
max string null Maximum size (e.g., "500px", "80%")
panel-id string auto-generated Unique identifier for save/load

Features

  • Glued Handles: Handles at intersections move together automatically. Hold Ctrl while dragging to resize independently.
  • iFrame Support: An overlay prevents losing mouse events when dragging over iframes.
  • Dark Mode: Uses CSS light-dark() for automatic theme adaptation.
  • Save/Load: Use ResizableLayoutRegistry to save and restore layouts.
  • Touch Support: Full touch support for mobile devices.

Save/Load Configuration

import { ResizableLayoutRegistry } from '@softwarity/resizable';

// Save current layout
const config = ResizableLayoutRegistry.getLayoutConfig();
localStorage.setItem('my-layout', JSON.stringify(config));

// Restore layout
const saved = localStorage.getItem('my-layout');
if (saved) {
  ResizableLayoutRegistry.applyLayoutConfig(JSON.parse(saved));
}

// Reset to initial state
ResizableLayoutRegistry.resetLayout();

Theming

The component uses CSS custom properties with light-dark() for theme support:

/* Customize handle colors */
resizable-handle {
  --handle-color: light-dark(#cccccc, #555555);
  --handle-hover-color: light-dark(#888888, #888888);
  --handle-active-color: light-dark(#666666, #aaaaaa);
  --handle-glued-color: light-dark(#4a90d9, #5ba0e9);
}

For frameworks using classes for dark mode (Tailwind, Bootstrap), sync color-scheme:

/* Tailwind */
html.dark { color-scheme: dark; }

/* Bootstrap */
[data-bs-theme="dark"] { color-scheme: dark; }
